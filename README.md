# Ember

A calm, fully offline life app for Android: habits, food, workouts, mobility, money, plans, German and career growth.

**Keep it lit.** Do about 6 in 10 of today's habits (small versions count) to keep your ember burning. Miss one day and it dims; miss two in a row and it goes out.

- `www/` the app (plain HTML, CSS and JavaScript, no build step)
- `android/` the Capacitor Android project, with native widgets, a phone-calendar bridge, Health Connect and offline barcode scanning
- `.github/workflows/build-apk.yml` builds the APK on every push and publishes it as the latest release

Download: https://github.com/youss8/questline/releases/latest/download/Questline.apk
