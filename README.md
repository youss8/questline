# Ember

A fully offline life dashboard for Android: habits, an auto-planned day, food, workouts, mobility, money, tasks, German and career growth.

- **Home** is a dashboard of live tiles; tap a tile to act.
- **My day** is a timeline planned around your fixed schedule.
- **Insights** holds the coach and weekly, monthly and 90-day reports.

`www/` is the app (plain HTML, CSS and JavaScript, no build step). `android/` is the Capacitor project with native widgets, a phone-calendar bridge, Health Connect and offline barcode scanning. `.github/workflows/build-apk.yml` builds the APK on every push.
